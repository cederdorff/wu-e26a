## Dagens fokus

Nu hvor I har byggeklodserne til et fungerende API, skal vi lære at kommunikere med det fra browseren. Fetch API'et gør det muligt at sende data frem og tilbage mellem browser og server uden at genindlæse siden. Det giver mulighed for en Single Page App (SPA) arkitektur, hvor vi ikke behøver at reloade hele siden og alle dens assets hver gang brugeren sender en besked til chatbotten.

---

## Agenda

- Git branches til at adskille forskellige udviklingsspor (og skifte imellem dem)
- Fetch API og moderne JavaScript til server kommunikation
- Promise håndtering og async/await syntax for asynkron programmering
- Opdatér DOM'en dynamisk baseret på server responses
- Hands-on: Byg en lille kortspils-app op imod et eksisterende API

**Fetch og async JS:**

- Læs ["Introducing asynchronous JavaScript"](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Async_JS/Introducing) på MDN
