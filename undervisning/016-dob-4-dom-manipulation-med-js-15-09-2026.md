## Dagens fokus

I en historisk kontekst er vi startet lidt baglæns, ved at skrive JavaScript på serveren. I dag tager vi det hjem hvor det startede; i browseren. Vi kigger på hvordan JavaScript loades og eksekveres i browseren, hvordan man manipulerer DOM'en, og hvordan man reagerer på brugerens handlinger.

Vi kigger også på Git remotes og hvordan vi kan push'e og pull'e fra flere remote repositories fra ét lokalt repo (så I fx både kan have AMAbot'en på jeres eget repo, og pushe til et repo, som vi kontrollerer).

---

## Agenda

- Git workflow: opsæt flere remotes til ét lokalt repository, så samme kode kan pushes flere steder hen
- Forskellige måder at loade scripts i browseren og deres indflydelse på performance
- DOM manipulation — hvordan ændrer man på siden efter den er loaded?
- Event handling og listeners — reagér på klik, tastetryk og andre brugerhandlinger
- Client-side form validering for bedre brugeroplevelse
