# DOB 1 - Form submits og Git basics - 01-09-2026

## Dagens fokus

Nu har I eksperimenteret med JavaScript på serveren og snust til Node og Express. I dag påbegynder vi en "AMAbot" frontend i browseren og opbygger et statisk UI i HTML, CSS og forms — som (historisk set) er fundamentet for alle interaktive web-oplevelser. Vi (gen-)introducerer også Git, som er det vigtigste værktøj til at holde styr på jeres kode og samarbejde med andre udviklere.

---

## Agenda

- HTML form basics: semantisk markup, forskellige form elementer og deres anvendelse
- GET vs POST requests fra klient perspektivet, hvornår bruger vi hvad?
- CSS til form styling og forbedring af brugeroplevelsen
- Introduktion til Git: repositories, commits og grundlæggende workflow
- Opsætning af Git til jeres projekter og første commits

---

## Forberedelse

**Forms**:

- Gennemgå ["Your first form"](https://developer.mozilla.org/en-US/docs/Learn/Forms/Your_first_form)  og ["How to structure a web form"](https://developer.mozilla.org/en-US/docs/Learn/Forms/How_to_structure_a_web_form) på MDN
- Gennemgå gerne ["Fullstack > Essential JavaScript > Build a Cookie Consent"](https://scrimba.com/fullstack-path-c0fullstack) forløbet på Scrimba, særligt afsnittene om Forms og FormData.

**Git (særligt hvis du kommer fra GitHub Desktop)**:

- [Installer Git](https://docs.github.com/en/get-started/git-basics/set-up-git) på din maskine og konfigurér [brugernavn](https://docs.github.com/en/get-started/git-basics/setting-your-username-in-git) og [email](https://docs.github.com/en/account-and-profile/how-tos/setting-up-and-managing-your-personal-account-on-github/managing-email-preferences/setting-your-commit-email-address), hvis ikke du har det i forvejen. Bemærk at hvis du kun har brugt GitHub Desktop, så skal du installere og konfigurere Git igen for at kunne bruge det fra VS Code og terminalen. Du skal kunne køre disse tre kommandoer i terminalen for at verficere at alt er sat korrekt op:
    - `git -v` skal vise en opdateret version af Git (`2.50` eller nyere)
    - `git config --global user.name` skal vise dit navn
    - `git config --global user.email` skal vise den email adresse, du også har konfigureret på GitHub — allerhelst din skolemail (du kan tilføje flere email adresser på GitHub)
- Opret en (gratis) bruger på [GitHub](https://github.com/) hvis du ikke allerede har en
- Læs de introducerende kapitler om Git i GitHubs dokumentation for at genopfriske din viden:
    - [About Git](https://docs.github.com/en/get-started/using-git/about-git)
    - [Pushing commits to a remote repository](https://docs.github.com/en/get-started/using-git/pushing-commits-to-a-remote-repository)
    - [Getting changes from a remote repository](https://docs.github.com/en/get-started/using-git/getting-changes-from-a-remote-repository)
- Sæt dig også ind i VS Codes support for Git, hvis ikke du har brugt det før:
    - [Using Git source control in VS Code](https://code.visualstudio.com/docs/sourcecontrol/overview)
    - [Introduction to Git in VS Code](https://code.visualstudio.com/docs/sourcecontrol/intro-to-git)
