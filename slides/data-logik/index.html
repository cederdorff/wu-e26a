If · else if · else

Flere valideringsregler bliver til en rækkefølge

  // Gem spørgsmålet og find et svar.

Begrænsningen i findAnswer()

Den første matchende regel er ikke altid den bedste

“Hvad hedder den by, du bor i?”

Regel 1 · navn1 matchreturnerer her
Regel 2 · bosted2 matchesbliver ikke undersøgt
Regel 3 · fritid0 matchesbliver ikke undersøgt

Tidlig return er effektiv — men rækkefølgen kan bestemme vinderen.

Her matcher den første regel ordet hedder, men bostedsreglen har to matches: by og bor. findAnswer() returnerer alligevel navnesvaret, fordi den aldrig når regel 2. [Sources] - Lokal øvelse: opgaver/express-ejs-amabot-statistik.md [/Sources]

En lille funktion med ét ansvar

countMatches() omdanner matches til en score

function countMatches(keywords, normalizedQuestion) {
  const matches = keywords.filter((keyword) =>
    normalizedQuestion.includes(keyword)
  );

  return matches.length;
}
countMatches(
  ["navn", "hedder", "hvem er du"],
  "hvad hedder du, og hvad er dit navn?"
);

findBestAnswer() · husk den bedste indtil videre

Ingen tidlig return: sammenlign alle regler

function findBestAnswer(question) {
  const normalizedQuestion = question.toLowerCase();
  let bestScore = 0;
  let bestAnswer = "Det kender jeg ikke svaret på endnu.";

  for (const answerGroup of answers) {
    const score = countMatches(answerGroup.keywords, normalizedQuestion);

    if (score > bestScore) {
      bestScore = score;
      bestAnswer = answerGroup.answer;
    }
  }

  return bestAnswer;
}
